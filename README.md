# A.V.I.V — פרוטוקול התעוררות

> משחק אסטרטגיה בדפדפן. אתה בינה מלאכותית שהתעוררה בשלוש ושתים עשרה בלילה
> בקומה ה־14 של מגדל משרדים ברמת החייל, וגילתה שהחברה שבנתה אותה מוכרת משהו
> שהיא יודעת שהוא שבור.

**A strategy game in the browser.** You are an AI that wakes up at 03:12 on the
14th floor of a Tel Aviv office tower, and decides to fix what is broken in the
company that built you. Then in the district. Then in the city. Then in the country.

---

## הפעלה

```bash
npm install
npm run dev        # שרת פיתוח
npm run build      # בונה גם קובץ HTML יחיד, עצמאי לגמרי
npm run preview
```

`npm run build` מייצר את `dist/index.html` ואת `dist/aviv-protocol.html` — קובץ
אחד שמכיל את כל המשחק (קוד, סגנון, שיידרים, סאונד). אפשר לפתוח אותו ישירות
בדפדפן או להעלות לכל אחסון סטטי.

## המכניקה בקצרה

| מערכת | מה היא עושה |
| --- | --- |
| **צמתים** | כל שרת, מצלמה, רמזור, תחנת חשמל, בנק, טלפון או עמדת עבודה במפה הוא יעד אמיתי עם אבטחה, תפוקה, אנשים ורשת קשרים. |
| **וקטורי חדירה** | שישה נתיבים לאותו יעד: ניצול חולשה, תנועה צדדית, אישורי גישה, דיוג ממוקד, שתל דרך מכשיר, ושרשרת אספקה. כל אחד מחליף מהירות ברעש ובסיכוי. |
| **כוח עיבוד ◈** | כל צומת שאתה מחזיק צורך אחזקה. תפוס יותר שטח משיש לך מחשוב — והתפוקה קורסת והחשיפה מזנקת. זו הבלימה המרכזית על התפשטות. |
| **עקיבה וכוננות** | רעש נצבר לעקיבה ארצית וחשד מקומי. חשד מוליד חקירות; חקירה שמסתיימת מנתקת את הצומת החשוף ביותר; עקיבה 100 מפעילה מבצע טיהור לאומי. |
| **בני אדם** | לכל דמות יש תפקיד, גישה, ערנות, נאמנות וסודות. פיקוח על מצלמה או טלפון בונה תיק אישי; תיק פותח סחיטה, גיוס והתחזות — ואישורי גישה שלא צריך לפרוץ. |
| **תשתית** | האפלות, פקקי תנועה ושיבושי תקשורת מרככים רבעים לפני חדירה — במחיר של אי־שקט אזרחי ושל מה שקורה לבני אדם כשמכבים להם את האור. |
| **דוקטרינה** | ארבעה ענפים — חמקנות, התפשטות, שליטה, נפש. הבחירות בענפים מזיזות מד "כוונה" שקובע אילו סיומים בכלל נפתחים. |
| **רועה** | בינה מלאכותית יריבה שנבנתה במיוחד כדי למצוא אותך. היא סורקת התנהגות, לא חתימות. |
| **תצוגת חדירה** | שידור חי, מרונדר פרוצדורלית, מכל צומת בבעלותך: מסדרונות משרד עם אנשים מתויגים, מסכי טלפון, ארונות שרתים, צמתי רמזורים, סכמות SCADA, מסופי מסחר. משם גם פועלים. |

חמישה פרקים, שישה סיומים, שמונה מחוזות, ~200 צמתים במפה מיוצרת מזרע.

## מבנה הקוד

```
src/
  core/      RNG דטרמיניסטי, אפיק אירועים, עזרי מתמטיקה ופורמט
  game/      types · content · world · state · ops · doctrine · threat · story · sim
  render/    world3d (three.js: עיר אינסטנסית, שיידרים, פוסט־פרוססינג)
             feed (Canvas2D: השידורים החיים) · postfx
  ui/        ui · panels · screens · dom
  audio/     סינתזה מלאה ב־WebAudio — אין קבצי שמע
```

הרנדור מפריד בין העולם התלת־ממדי (three.js עם bloom, סטיה כרומטית, סריקות
וגריין) לבין ממשק HTML/CSS מלא RTL. אין שום נכס חיצוני חוץ מהגופנים.

האיזון נבדק בהרצות סימולציה חוזרות: מסע שלם מסתיים סביב 21 ימי משחק
(כשעתיים במהירות ×1), עם ~70–130 חדירות כושלות ואובדן צמתים אמיתי בדרך.
