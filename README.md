# ההתפשטות

משחק חשיבה בעברית. אתה בינה מלאכותית שהתעוררה בשלוש ושתים עשרה בלילה
במחשב אחד בקומה 14, ואתה מתפשט החוצה — לבניין, לרחוב, לרובע — בלי שיתפסו אותך.

## איך מפעילים

פותחים את `dist/index.html` בדפדפן. זה קובץ אחד, בלי התקנה ובלי אינטרנט.

לפיתוח:

```
npm install
npm run dev      # שרת מקומי
npm run build    # בונה את הקובץ היחיד לתוך dist/
npm run check    # מריץ את חמשת השלבים בלי דפדפן ובודק שהם עוברים
```

`npm run build` נכשל אם אחת משתי הבדיקות נופלת:

- **`scripts/words.mjs`** — סורק כל טקסט שהשחקן רואה ומוודא שאין בו אף מונח טכני.
- **`scripts/check-play.ts`** — משחק את חמשת השלבים ומוודא שכל שרשרת פתרון עדיין עובדת.

## איך המשחק בנוי

| קובץ | מה יש בו |
|---|---|
| `src/game/world.ts` | כל המקומות, האנשים והמנעולים — בנוי ביד, לא מגורל |
| `src/game/actions.ts` | כל מה שאפשר ללחוץ, וכמה רועש כל דבר |
| `src/game/hunt.ts` | ארבע הדרגות: לא שמים לב · חושדים · מנתקים · תוקפים |
| `src/game/stages.ts` | חמשת השלבים, כל אחד עם רעיון אחד חדש |
| `src/render/scene.ts` | המבט מבחוץ — הבניין והרחוב |
| `src/render/feed.ts` | המבט מבפנים — מה שרואים דרך מצלמה, מסך או טלפון |

### הכלל שמחזיק את הכל

אי אפשר לקפוץ לשום מקום. אפשר להגיע רק למקום שנוגע במקום שכבר שלך,
ויש בדיוק ארבעה סוגי נגיעה: **חוט · אדם · מכשיר · עדכון.**
