# DAVID — פרק א׳: הָרֹעֶה

משחק תלת־ממדי קולנועי בדפדפן (three.js + TypeScript) על סיפורו של דוד המלך, כהצצה מבעד לעדשת סרט אל מה שמסופר בתנ״ך.
הפרק הראשון: דוד הנער רועה את צאן אביו בשדות בית לחם, מתאמן בקלע, ומציל שה מפי הדוב — לפי שמואל א׳ יז, לד–לז.
לפני הפרק מתנגן סרט פתיחה, **הַטּוֹב מִמֶּךָּ** (60 שניות, שש סצנות): שאול שנדחה בגלגל — וממלכתו שנקרעה ממנו ניתנת לנער הרועה בשדות בית לחם.

## הרצה

```bash
cd david
npm install
npm run dev            # http://localhost:5173
npm run build          # dist/ — אתר סטטי (כל הנכסים כקבצים נפרדים, נטענים לפי הצורך)
npm run build:artifact # dist-artifact/ — דף Artifact של claude.ai: index.html + assets/ + files.json + manifest.json
npm run build:single   # dist-single/index.html — קובץ HTML יחיד שכל הנכסים בתוכו (כבד: כל הדרגות וכל הדמויות)
```

המשחק דורש WebGL2 (כל דפדפן עדכני במחשב, iOS Safari 15 ומעלה, Chrome באנדרואיד). בנייד — מומלץ לסובב את המכשיר לרוחב.
לבדיקת מקורות: `python3 tools/sources/verify_sources.py --quiet` (קוד יציאה 0 = כל הציטוטים מדויקים).

## מהלך הפרק

1. **סרט הפתיחה — הַטּוֹב מִמֶּךָּ** (134.5 שניות; פרולוג, הגלגל, דוד, והמעבר למשחק בלי חיתוך; אותו חיתוך במחשב ובנייד):
   - **הפרולוג (61 שניות) — מתי, איפה, ומה עבר עם ישראל עד שם:**
     - **הארץ** — כרטיס הזמן (לִפְנֵי כִּשְׁלֹשֶׁת אֲלָפִים שָׁנָה) על רקע שחור; התמונה עולה מן השחור אל ים עננים בשחר מעל הרי יהודה, השמש עולה מעל הרי מואב. טיסה אחת איטית: שוקעת דרך מעטה העננים, יוצאת תחתיו אל הרכסים והערפל שבעמקים, הטרסות והזיתים, ים המלח מנצנץ במזרח — ונוטה לאט אל המערב עד שרכס בית לחם לפניה. הכרטיס: אֶרֶץ יִשְׂרָאֵל · הָרֵי יְהוּדָה, בִּימֵי שָׁאוּל הַמֶּלֶךְ. התפאורה בנויה על גובה אמיתי (SRTM).
     - **בית לחם** ו**קבר רחל** — עירו של ישי בבוקר, ומצבת קבורת רחל על דרך אפרת (בראשית לה, יט); משם העדשה מטפסת אל השמים.
     - **המפה** — נוף תלת־ממדי ריאליסטי של הארץ ממרום (גובה ותצלומי לוויין אמיתיים, בלי שום דבר מודרני): הדרך ממצרים, ארבעים שנה במדבר, מעבר הירדן אל הגלגל (יהושע ד, יט); השבטים בנחלותיהם בימים שאין מלך בישראל (שופטים כא, כה), וחמש ערי פלשתים.
     - **פלשתים** — המצלמה ממשיכה לרדת: מגובה רב מעל מישור החוף אל טור הצבא הצועד מאשדוד פנימה, הנחושת מבריקה והאבק בשמש הנמוכה (שמואל א׳ יג, יט על השמים).
     - **הרמה** — באור אחר הצהריים: זקני ישראל לפני שמואל בשער; אחד קם ותובע "שִׂימָה־לָּנוּ מֶלֶךְ" (שמואל א׳ ח, ה), ושמואל מסב את פניו (ח, ו). ואז — חיתוך חד על קול השופר.
   - **הגלגל** — צבא ישראל, רגלי, יוצא מן האבק אל העדשה, וקרני האיל נשמעות בשורה הראשונה (בדיוק הצילום של החיתוך הקודם מן השופר והלאה); שאול צועד בהילוך איטי בראש הצבא, השמש הנמוכה מאחוריו.
   - **החנית והדממה** — שאול נעצר ומניף את החנית והעם מריע ("מִשִּׁכְמוֹ וָמַעְלָה גָּבֹהַּ מִכָּל־הָעָם" (שְׁמוּאֵל א׳ ט, ב)); השאגה נקטעת לדממה, השורות נפתחות, ושמואל עומד בדרך ופוסע צעד אחד.
   - **הקריעה** — שמואל פונה ללכת, שאול הולך אחריו, כורע ואוחז בכנף מעילו, והכנף נקרעת בידו (טו, כז — בהילוך איטי).
   - **דבר ה׳** — שמואל חוזר ואומר: "קָרַע ה׳ אֶת־מַמְלְכוּת יִשְׂרָאֵל מֵעָלֶיךָ הַיּוֹם" (שְׁמוּאֵל א׳ טו, כח), ושתיקה ארוכה אחריו; שאול נשאר לבדו, הכנף הקרועה באגרופו.
   - **דוד** — הבזק אור חם אל שדות בית לחם: דוד על הסלע מעל העדר, נגד שמש נמוכה, וחציו השני של הפסוק נכתב מעליו: "וּנְתָנָהּ לְרֵעֲךָ הַטּוֹב מִמֶּךָּ" (שְׁמוּאֵל א׳ טו, כח; לפי מצודת דוד: "לרעך. זהו דוד"); פניו פונות אל האור.
   - **העדר, הטלה והלוגו** — דוד משגיח בעדרו כמה שניות ותהלים עח, ע–עא נכתב בשמים; אחר כך, בצילום ארוך אחד, הוא יורד אל טלה שנשאר מאחור, אוסף אותו בזרועותיו ונושא אותו אל אמו — ובשמים נוצר הלוגו **DAVID**, ותחתיו דָּוִד ופֶּרֶק רִאשׁוֹן · הָרֹעֶה; לבסוף המצלמה נסוגה ויורדת מעט אל מאחורי דוד, בדיוק אל מצלמת המשחק, והמשחק מתחיל בלי חיתוך ובלי שחור. הדילוג (Enter / Esc / הכפתור) קופץ ישר אל המעבר הזה.
   - המעברים: ההתכה (dissolve) אינה מקפיאה את הצילום היוצא — התמונה האחרונה שלו ממשיכה לנוע עם המצלמה שלו (הטיסה ממשיכה לטוס, הטיפוס ממשיך לטפס) בזמן שהיא דועכת; בין שני חלקי המפה החיתוך בלתי נראה.
   - הסרט מלווה בפסקול מסונתז שנכתב לפי התמונה ונעול לה.
   - התפאורות של הסרט נבנות כל אחת בנפרד ובצעדים קטנים (FilmStage.buildSet), כך שאפשר להתחיל את הסרט כשהארץ מוכנה ולבנות את השאר ברקע.
2. **בשדה** — הליכה אל הצאן (הדרכת תנועה), קריאה לעדר (עם המדרש משמות רבה ב, ב על דוד הרועה), איסוף חמישה חלוקי אבנים מן הנחל ("וַיִּבְחַר־לוֹ חֲמִשָּׁה חַלֻּקֵי־אֲבָנִים מִן־הַנַּחַל וַיָּשֶׂם אֹתָם בִּכְלִי הָרֹעִים" (שְׁמוּאֵל א׳ יז, מ)), ואימון בקלע על שלושה כדי חרס שעל הגדר ("כָּל־זֶה קֹלֵעַ בָּאֶבֶן אֶל־הַשַּׂעֲרָה וְלֹא יַחֲטִא" (שׁוֹפְטִים כ, טז)).
3. **הדוב** — "וּבָא הָאֲרִי וְאֶת־הַדּוֹב וְנָשָׂא שֶׂה מֵהָעֵדֶר" (שְׁמוּאֵל א׳ יז, לד):
   - **הסבך** (קטע קולנועי קצר, כחמש שניות) — הטלה תועה אל שולי השיחים שבדרך אל הסבך ורועה שם; ציפורים עפות מן השיחים ומשתתקות; האור דועך בצל; ובחושך שבין השיחים נפתחות שתי עיניים ענבריות חיוורות — וגוף הדוב לא נראה. רק אז הדוב יוצא אל הטלה.
   - "וְיָצָאתִי אַחֲרָיו" — מרדף, ופגיעות בקלע או במקל.
   - "וְהִכִּתִיו וְהִצַּלְתִּי מִפִּיו" (שְׁמוּאֵל א׳ יז, לה) — חילוץ השה מלסתות הדוב בלחיצות מהירות.
   - "וַיָּקָם עָלַי" (שְׁמוּאֵל א׳ יז, לה) — הדוב מזדקף על רגליו האחוריות; מתחמקים ממכותיו עד שהוא מאבד שיווי משקל.
   - "וְהֶחֱזַקְתִּי בִּזְקָנוֹ" (שְׁמוּאֵל א׳ יז, לה) — תפיסה בזקן.
   - "וְהִכִּתִיו וַהֲמִיתִּיו" (שְׁמוּאֵל א׳ יז, לה) — שלוש מכות מקל מתוזמנות.
4. **הדרך הביתה** — דוד מרים את השה על כתפיו ומשיב אותו לעדר, בשקיעה: "ה׳ אֲשֶׁר הִצִּלַנִי מִיַּד הָאֲרִי וּמִיַּד הַדֹּב הוּא יַצִּילֵנִי" (שְׁמוּאֵל א׳ יז, לז), ו־"גַּם כִּי־אֵלֵךְ בְּגֵיא צַלְמָוֶת לֹא־אִירָא רָע כִּי־אַתָּה עִמָּדִי שִׁבְטְךָ וּמִשְׁעַנְתֶּךָ הֵמָּה יְנַחֲמֻנִי" (תְּהִלִּים כג, ד).
   בכרטיס הסיום: "גַּם אֶת־הָאֲרִי גַּם־הַדֹּב הִכָּה עַבְדֶּךָ" (שְׁמוּאֵל א׳ יז, לו–לז), והצצה לפרק הבא — המשיחה ("מַלֵּא קַרְנְךָ שֶׁמֶן וְלֵךְ אֶשְׁלָחֲךָ אֶל־יִשַׁי בֵּית־הַלַּחְמִי כִּי־רָאִיתִי בְּבָנָיו לִי מֶלֶךְ" (שְׁמוּאֵל א׳ טז, א)). אפשר להמשיך לשוטט בשדה או לשחק שוב.

## מה נבדק מול המקורות

- **כל ציטוט** (פסוק, מדרש, תרגום) נלקח מקטלוג אחד, `src/content/sources.ts`, שנבנה מתוך טקסטים של ספריא (מקרא על פי המסורה, מדרש רבה ועוד — ראו `docs/sources.md`) ונבדק בכלי `tools/sources/verify_sources.py`: 183 רשומות, 0 אי־התאמות. אף פסוק לא הוקלד ידנית, והשם המפורש מופיע תמיד כ־ה׳.
- **בסרט שבעה טקסטים בלבד**: הכרטיסים הם קריינות (הזמן, הַגִּלְגָּל, שָׁאוּל · מֶלֶךְ יִשְׂרָאֵל, שְׁמוּאֵל), ואינם מעוצבים כפסוק; רק פסוקים מן הקטלוג מוצגים כפסוק, מילה אחר מילה ועם המקור.
- **הסרט נעצר לפני המשיחה** (טז, יג): אין בו רוח רעה, אין כינור בחצר, אין גוליית ואין אגג; צבא ישראל רגלי, בלי סוסים ובלי תופים בשורות (התופים — בפסקול בלבד).
- **סיפור הדוב** בנוי צעד אחר צעד לפי שמואל א׳ יז, לד–לו: הדוב נושא שה מן העדר, דוד יוצא אחריו, מכה אותו, מציל מפיו, הדוב קם עליו, דוד מחזיק בזקנו, מכה וממית.
- **הרמת השה על הכתפיים** היא תמונה אמנותית: המדרש על הרועה הנושא גדי על כתפו נאמר על משה (שמות רבה ב, ב), ולכן אינו מוצג ככתובית לסצנה הזאת.
- **תקופת הברזל (כ־1000 לפנה״ס)**: שמואל בשיער ארוך שלא נגע בו תער ובמעיל צמר כהה שבכנפותיו ציצית עם פתיל תכלת; שאול גבוה מכל העם, בשריון קשקשים מנחושת, הנזר והחנית, והקובע תחת זרועו; אין שעטנז (צמר ופשתים בבגד אחד).
  **הקריעה** לפי פשוטו של מקרא (רש״י, רד״ק, מצודת דוד על טו, כז): שאול אחז בכנף מעיל שמואל — והכנף נקרעה. הכנף הנשארת בידו של שאול אחר כך היא היסק קולנועי.
- **דוד** — "וְהוּא אַדְמוֹנִי עִם־יְפֵה עֵינַיִם וְטוֹב רֹאִי" (שְׁמוּאֵל א׳ טז, יב): נער צעיר, שיער ערמוני מתולתל, עור שזוף ונמשים, כותונת צמר גסה ולא צבועה, חגורת חבלים, ילקוט הרועים על הירך, סנדלים, מקל מסוקס וקלע ("וַיִּבְחַר־לוֹ חֲמִשָּׁה חַלֻּקֵי־אֲבָנִים מִן־הַנַּחַל וַיָּשֶׂם אֹתָם בִּכְלִי הָרֹעִים" (שְׁמוּאֵל א׳ יז, מ)) — לפי תמונת הייחוס.
- **הנוף והחיות** — רכס בית לחם, מדרגות חקלאיות עם כתלי אבן יבשה, זיתים וברושים, סלעי גיר מחוררים, קרקע טרה רוסה; מצבת קבורת רחל בדרך אפרתה; כבשי עוואסי עם אליה ועזים שחורות; הדוב הסורי (Ursus arctos syriacus), הדוב שחי בארץ ישראל, בפרווה בהירה בגוון קש.

## טכנולוגיית הגרפיקה

- **בני אדם ריאליסטיים** — גופים מבוססי MakeHuman (CC0), בפרופורציות של דוד, שאול ואנשי החצר; עור אפוי במפות 2K/1K (צבע, נורמל, מסכות) עם פיזור אור תת־עורי, עיניים עם קשתית וקרנית, מצמוץ והבעות פנים, אצבעות, ועיוות רך במפרקים (dual‑quaternion skinning).
- **שיער בקווצות** — אלפי קווצות שיער וזקן שנוצרות בזמן הטעינה ומתנועעות ברוח ועם הראש (סימולציה בצילומים הקרובים).
- **לכידת תנועה** — תנועות מצולמות של אנשים אמיתיים (ספריית CMU וספריית Microsoft Rocketbox, רישיון MIT), מותאמות לשלד הדמויות ומשולבות במשחק פרוצדורלי: נשימה, מבט וסקאדות, מצמוץ, IK לידיים ולרגליים, כריעה, ודיבור לפי מילות הפסוק.
- **הקריעה** — סימולציית בד לכנף המעיל: הקרע רץ לאורך האריג, בשוליים פרומים, והכנף עם הציצית נשארת באגרוף.
- **המון** — צבאות של אלפי לוחמים על כרטיס המסך (GPU), כל אחד בקצב, צעד ומבט משלו, ושחקנים מלאים בשורה הקרובה למצלמה.
- **תלבושות** — בגדים שמותאמים לגוף בזמן הטעינה: הכותונת הארוגה, החגורה, הילקוט והסנדלים של דוד; המעיל, הכותונת, הנזר והחנית של שאול; מרקמי אריג עם ברק בד (sheen) ושוליים מתנועעים.
- **הדוב והעדר** — דוב שפוסל מפונקציות מרחק (SDF) עם 3 רמות פירוט, מפות PBR אפויות, פרווה בשכבות (shells) ואנימציה פרוצדורלית עם IK; כבשים, אילים, עזים וטלה עם רמות פירוט והתנהגות עדר.
- **העולם** — שטח עם מדרגות וכתלי אבן יבשה, סלעי גיר, עצי זית וברוש, עשב שמתנועע ברוח, בית לחם של תקופת הברזל, שמיים ועננים בשעת זהב.
- **תפאורות הסרט** — הגלגל (מישור יריחו מנתוני גובה אמיתיים, דקלים, שתים־עשרה האבנים, מחנה, אבק) ושדות בית לחם של המשחק עצמו; נבנית מאחורי מסך הטעינה רק התפאורה שהסרט מצלם בה (עם שחקניה וצבאה), ומשוחררת מהזיכרון מיד כשהסרט עוזב אותה.
- **שרשרת קולנועית** — TAA (החלקה טמפורלית), עומק שדה, bloom, ערפל אווירה וקרני אור, פס קולנוע 2.39:1 בסרט, מראה פילם, גרייד וחשיפה לכל צילום.
- **דרגות איכות** — בדיקת ביצועים קצרה בטעינה בוחרת דרגה: `desktop-high`, `desktop-medium`, `mobile-high`, `mobile-low`. טלפונים מקבלים תמיד את תוכן ה־low: מרקמים של 1K, פחות קווצות שיער, מעט קריאות ציור, ובלי הורדה של נכסי המחשב; התמונה מצוירת בצפיפות פיקסלים של פי 2 (`mobile-high`) או פי 1.5 (`mobile-low`), ובקצב של עד 60 פריימים בשנייה. אם קצב הפריימים נשאר נמוך לאורך זמן (למשל כשהמכשיר מתחמם), מנגנון ויסות מוריד עומס — קרני אור, bloom ואחר כך רזולוציית הצללים — בלי לשנות את גודל התמונה.
- **סאונד** — כל המוזיקה והאפקטים מסונתזים בזמן אמת (כינור, חליל, תופים, שופר, מקהלה, רוח, ציקדות, עדר); פסקול הסרט נעול לתמונה, לפי הנקודות המסומנות בתסריט.

## פרמטרים ב־URL

| פרמטר | משמעות |
|---|---|
| `?q=low\|medium\|high` | כפיית דרגת גרפיקה (בטלפון `high` = `mobile-high`); אפשר גם שם דרגה: `desktop-high`, `desktop-medium`, `mobile-high`, `mobile-low` |
| `?skip=1` | דילוג על הפתיח |
| `?preload=0` | לא לבנות את תפאורות הסרט מאחורי מסך הטעינה (הסרט יבנה אותן אחרי ההתחלה) |
| `?jump=sling\|bear\|fight\|end` | קפיצה ישירה לשלב (לפיתוח) |

| `?fps=max` | בלי הגבלת 60 פריימים בשנייה בנייד |
| `?watchdog=1` | בדיקת פריימים שחורים (אבחון) |
| `?test=1`, `?introAt=<שניות>`, `?precompile=1`, `?filmkeep=1`, `?filmsets=gilgal`, `?filmcast=0`, `?filmcrowd=0` | ווים לבדיקות אוטומטיות |

## מגבלות ידועות

זה עדיין משחק דפדפן שרץ גם בטלפון, ולכן אינו מגיע לרמה של משחקי הקונסולה הגדולים. הפנים נראות ריאליסטיות במרחק משחק ובצילומים מוארים מאחור, אבל בתקריב עדיין מורגש שהן ממוחשבות; כל המוזיקה מסונתזת (בלי הקלטות); והסרט נבדק בדפדפן עם רינדור תוכנה — לא על כל מכשיר אמיתי.
