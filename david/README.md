# DAVID — פרק א׳: הרועה

משחק תלת־ממדי סינמטי בדפדפן (Three.js + TypeScript) על סיפורו של דוד המלך.
הפרק הראשון: דוד הרועה בשדות בית לחם, ההצלה של השה מפי הדוב — לפי שמואל א׳ יז, לד–לז.

## הרצה

```bash
cd david
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/ (אתר סטטי)
npm run build:single # dist-single/index.html — קובץ HTML יחיד עם כל המרקמים בפנים
```

פרמטרים ב־URL:

| פרמטר | משמעות |
|---|---|
| `?q=low\|medium\|high` | כפיית רמת גרפיקה (ברירת מחדל: high במחשב, low בנייד) |
| `?skip=1` | דילוג על פתיח הסינמטי |
| `?jump=sling\|bear\|fight\|end` | קפיצה ישירה לשלב (לפיתוח) |

## מהלך הפרק

1. **פתיח סינמטי** — מעוף מעל הרי יהודה, מדרגות הזיתים שמתחת לבית לחם, מצבת קבורת רחל בדרך אפרתה, הצאן במרעה, ודוד על הסלע. בסוף מופיעה הכותרת **DAVID**.
2. **היכרות** — הליכה אל הצאן, קריאה לעדר (בליווי המדרש משמות רבה ב, ב), איסוף חמישה חלוקי אבנים מן הנחל, ואימון בקלע על כדי חרס (שופטים כ, טז).
3. **הדוב** — "וּבָא הָאֲרִי וְאֶת־הַדּוֹב וְנָשָׂא שֶׂה מֵהָעֵדֶר":
   - "וְיָצָאתִי אַחֲרָיו" — מרדף.
   - "וְהִכִּתִיו" — פגיעות בקלע או במקל.
   - "וְהִצַּלְתִּי מִפִּיו" — חילוץ השה מלסתות הדוב, בלחיצות מהירות.
   - "וַיָּקָם עָלַי" — הדוב מזדקף על רגליו האחוריות.
   - התחמקות ממכותיו עד שהוא מאבד שיווי משקל.
   - "וְהֶחֱזַקְתִּי בִּזְקָנוֹ" — תפיסה בזקן.
   - "וְהִכִּתִיו וַהֲמִיתִּיו" — שלוש מכות מקל מתוזמנות.
4. **סיום** — דוד נושא את השה על כתפיו ומשיב אותו לעדר, בשקיעה. הפרק נחתם בפסוקים "ה׳ אֲשֶׁר הִצִּלַנִי מִיַּד הָאֲרִי וּמִיַּד הַדֹּב" ו"שִׁבְטְךָ וּמִשְׁעַנְתֶּךָ הֵמָּה יְנַחֲמֻנִי". בסוף מוצגת הצצה לפרק הבא: המשיחה בידי שמואל.

## דיוק היסטורי ומקראי

- **דוד** — "אַדְמוֹנִי עִם־יְפֵה עֵינַיִם וְטוֹב רֹאִי" (שמ״א טז, יב): שיער ערמוני מתולתל, כותונת צמר/פשתן לא צבועה, חגורת עור, ילקוט הרועים, סנדלים, מקל וקלע (שמ״א יז, מ). כמו בתמונת הרפרנס.
- **הנוף** — רכס בית לחם, מדרגות חקלאיות עם כתלי אבן יבשה, זיתים, אלון ואלה, סירה קוצנית, סלעי גיר, קרקע טרה רוסה, נחל יבש עם חלוקים. במזרח מתגלים מדבר יהודה, ים המלח והרי מואב.
- **בית לחם** — כפר מתקופת הברזל: בתים מאבן בני קומה אחת או שתיים, גגות שטוחים, חומה ושער. ליד השער יש בור מים ("מִבֹּאר בֵּית־לֶחֶם אֲשֶׁר בַּשָּׁעַר", שמ״ב כג, טו).
- **הצאן** — כבשי עוואסי עם אליה (האליה מוזכרת בתורה) לצד עזים שחורות ארוכות אוזניים.
- **הדוב** — דוב סורי (Ursus arctos syriacus), הדוב שחי בארץ ישראל: פרווה בהירה בגוון קש־זהב, דבשת כתפיים וציפורניים בהירות.

## מבנה הקוד

```
src/
  core/        Engine (רנדרר, סצנה, איכות), Input (מקלדת/עכבר/מגע), Colliders, noise, Shared uniforms
  world/       Terrain (גובה, מדרגות, נחל, אפייה של הצללה), Sky (שמיים ועננים), Vegetation, Grass (GPU),
               Rocks, Village (בית לחם), Textures, Layout (מפת הפרק)
  fx/          PostFX (ערפל אווירה, קרני אור, bloom, grading), Particles (עשן, אבק, חלקיקים באוויר)
  characters/  DavidModel (מודל פרוצדורלי + אנימציה + IK לרגליים + קלע), BearModel (פרווה ב-shell texturing),
               Flock (כבשים ועזים + התנהגות עדר), Rig (מערכת פוזות), Rope
  gameplay/    Story (תסריט הפרק), Player, BearActor, CameraRig (מצלמה חופשית וסינמטית), Projectiles, Props, GameAudio
  audio/       AudioEngine — מוזיקה ואפקטים שכולם מסונתזים בזמן אמת (כינור/לירה, תופים, שופר, מקהלה, רוח, ציקדות)
  ui/          UI + style.css — טעינה, כותרות, פסוקים, HUD, QTE, תפריטים
tools/gen_textures.py — מחולל המרקמים (numpy/Pillow), כולם tileable
```

כל התוכן נוצר פרוצדורלית (גיאומטריה, מרקמים, סאונד), ללא נכסים חיצוניים.

## הערה על רמת הגרפיקה

זה אב־טיפוס שרץ בדפדפן, ולכן הוא לא יגיע לרמת Red Dead Redemption 2. מה שכן עשיתי כדי להתקרב לתחושה: תאורת שעת זהב, ערפל אווירה, קרני אור, צללים רכים, עשב ועצים שזזים ברוח, פרוות דוב ומצלמה קולנועית.
למשחק מסחרי ברמה הזו, הדרך המקובלת היא Unreal Engine 5: MetaHuman לדמויות, לכידת תנועה (mocap), סריקות פוטוגרמטריה של נופי יהודה, וצוות אמנים ואנימטורים. הקוד כאן יכול לשמש vertical slice ובסיס לעיצוב הפרקים.
