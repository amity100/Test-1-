# DAVID — פרק א׳: הָרֹעֶה

משחק תלת־ממדי קולנועי בדפדפן (three.js + TypeScript) על סיפורו של דוד המלך, כהצצה מבעד לעדשת סרט אל מה שמסופר בתנ״ך.
הפרק הראשון: דוד הנער רועה את צאן אביו בשדות בית לחם, מתאמן בקלע, ומציל שה מפי הדוב — לפי שמואל א׳ יז, לד–לז.
במקביל, בפתיח, מציץ הסרט אל בית שאול בגבעת שאול: מלך גבוה ומרשים, חניתו בידו, מול חייו הפשוטים של הרועה.

## הרצה

```bash
cd david
npm install
npm run dev            # http://localhost:5173
npm run build          # dist/ — אתר סטטי (כל הנכסים כקבצים נפרדים, נטענים לפי הצורך)
npm run build:artifact # dist-artifact/ — דף Artifact של claude.ai: index.html + assets/ + files.json + manifest.json
npm run build:single   # dist-single/index.html — קובץ HTML יחיד שכל הנכסים בתוכו (כבד: כל הדרגות וכל הדמויות)
```

המשחק דורש WebGL2 (כל דפדפן עדכני במחשב, iOS Safari 15 ומעלה, Chrome באנדרואיד). בנייד — מומלץ לסובב את המכשיר לרוחב.
לבדיקת מקורות: `python3 tools/sources/verify_sources.py --quiet` (קוד יציאה 0 = כל הציטוטים מדויקים).

## מהלך הפרק

1. **הפתיח — שני עולמות** (כ־104 שניות במחשב; גרסה מקוצרת של כ־88 שניות בנייד). חיתוך מקביל בין שדות בית לחם לבין בית שאול בגבעת שאול, בבוקר שלפני המשיחה (שמואל א׳ טו, לד – טז, א):
   - שחר מעל הרי יהודה ← גבעת שאול בנחלת בנימין, המצודה על הגבעה ("וְשָׁאוּל עָלָה אֶל־בֵּיתוֹ גִּבְעַת שָׁאוּל" (שְׁמוּאֵל א׳ טו, לד)).
   - שאול יושב תחת האשל וחניתו בידו, ועבדיו נצבים עליו ("וְשָׁאוּל יוֹשֵׁב בַּגִּבְעָה תַּחַת־הָאֶשֶׁל בָּרָמָה וַחֲנִיתוֹ בְיָדוֹ וְכָל־עֲבָדָיו נִצָּבִים עָלָיו" (שְׁמוּאֵל א׳ כב, ו) — פסוק מתקופה מאוחרת יותר, מוצג כדיוקן של החצר ועם המקור בלבד).
   - חיתוך תואם מאגרוף המלך על החנית אל ידו של הרועה על מקלו, בין הצאן ("עוֹד שָׁאַר הַקָּטָן וְהִנֵּה רֹעֶה בַּצֹּאן" (שְׁמוּאֵל א׳ טז, יא)).
   - דיוקן המלך ("מִשִּׁכְמוֹ וָמַעְלָה גָּבֹהַּ מִכָּל־הָעָם" (שְׁמוּאֵל א׳ ט, ב)); אבנר בן נר ואנשי החיל (במחשב בלבד).
   - דוד והשה ← השמש הופכת ללהבת נר: ערב בבית שאול, המלך לבדו; כנף המעיל הקרועה — זיכרון הגלגל ("קָרַע ה׳ אֶת־מַמְלְכוּת יִשְׂרָאֵל מֵעָלֶיךָ הַיּוֹם וּנְתָנָהּ לְרֵעֲךָ הַטּוֹב מִמֶּךָּ" (שְׁמוּאֵל א׳ טו, כח)).
   - דרך אור חם אל בית לחם, מצבת קבורת רחל, העדר, ודוד על הסלע ("וְהוּא אַדְמוֹנִי עִם־יְפֵה עֵינַיִם וְטוֹב רֹאִי" (שְׁמוּאֵל א׳ טז, יב)), ועגורן עד הכותרת **DAVID**.
   - הפתיח כולו מלווה בפסקול מסונתז שנכתב לפי התמונה: אצל שאול — תופי מסגרת עמוקים, מיתרים נמוכים, קולות גברים ושופר (בלי כינור בבית המלך); אצל דוד — חליל רועים, כינור ותוף מסגרת.
2. **בשדה** — הליכה אל הצאן (הדרכת תנועה), קריאה לעדר (עם המדרש משמות רבה ב, ב על דוד הרועה), איסוף חמישה חלוקי אבנים מן הנחל ("וַיִּבְחַר־לוֹ חֲמִשָּׁה חַלֻּקֵי־אֲבָנִים מִן־הַנַּחַל וַיָּשֶׂם אֹתָם בִּכְלִי הָרֹעִים" (שְׁמוּאֵל א׳ יז, מ)), ואימון בקלע על שלושה כדי חרס שעל הגדר ("כָּל־זֶה קֹלֵעַ בָּאֶבֶן אֶל־הַשַּׂעֲרָה וְלֹא יַחֲטִא" (שׁוֹפְטִים כ, טז)).
3. **הדוב** — "וּבָא הָאֲרִי וְאֶת־הַדּוֹב וְנָשָׂא שֶׂה מֵהָעֵדֶר" (שְׁמוּאֵל א׳ יז, לד):
   - "וְיָצָאתִי אַחֲרָיו" — מרדף, ופגיעות בקלע או במקל.
   - "וְהִכִּתִיו וְהִצַּלְתִּי מִפִּיו" (שְׁמוּאֵל א׳ יז, לה) — חילוץ השה מלסתות הדוב בלחיצות מהירות.
   - "וַיָּקָם עָלַי" (שְׁמוּאֵל א׳ יז, לה) — הדוב מזדקף על רגליו האחוריות; מתחמקים ממכותיו עד שהוא מאבד שיווי משקל.
   - "וְהֶחֱזַקְתִּי בִּזְקָנוֹ" (שְׁמוּאֵל א׳ יז, לה) — תפיסה בזקן.
   - "וְהִכִּתִיו וַהֲמִיתִּיו" (שְׁמוּאֵל א׳ יז, לה) — שלוש מכות מקל מתוזמנות.
4. **הדרך הביתה** — דוד מרים את השה על כתפיו ומשיב אותו לעדר, בשקיעה: "ה׳ אֲשֶׁר הִצִּלַנִי מִיַּד הָאֲרִי וּמִיַּד הַדֹּב הוּא יַצִּילֵנִי" (שְׁמוּאֵל א׳ יז, לז), ו־"גַּם כִּי־אֵלֵךְ בְּגֵיא צַלְמָוֶת לֹא־אִירָא רָע כִּי־אַתָּה עִמָּדִי שִׁבְטְךָ וּמִשְׁעַנְתֶּךָ הֵמָּה יְנַחֲמֻנִי" (תְּהִלִּים כג, ד).
   בכרטיס הסיום: "גַּם אֶת־הָאֲרִי גַּם־הַדֹּב הִכָּה עַבְדֶּךָ" (שְׁמוּאֵל א׳ יז, לו–לז), והצצה לפרק הבא — המשיחה ("מַלֵּא קַרְנְךָ שֶׁמֶן וְלֵךְ אֶשְׁלָחֲךָ אֶל־יִשַׁי בֵּית־הַלַּחְמִי כִּי־רָאִיתִי בְּבָנָיו לִי מֶלֶךְ" (שְׁמוּאֵל א׳ טז, א)). אפשר להמשיך לשוטט בשדה או לשחק שוב.

## מה נבדק מול המקורות

- **כל ציטוט** (פסוק, מדרש, תרגום) נלקח מקטלוג אחד, `src/content/sources.ts`, שנבנה מתוך טקסטים של ספריא (מקרא על פי המסורה, מדרש רבה ועוד — ראו `docs/sources.md`) ונבדק בכלי `tools/sources/verify_sources.py`: 125 רשומות, 0 אי־התאמות. אף פסוק לא הוקלד ידנית, והשם המפורש מופיע תמיד כ־ה׳.
- **כתוביות הן קריינות בלבד** (שמות מקומות ואנשים), בלי מירכאות ובלי "על פי". מקום מושבו של שאול נקרא "בֵּית שָׁאוּל" / "גִּבְעַת שָׁאוּל" — לעולם לא "ארמון" (המילה אינה מופיעה בספר שמואל).
- **הפתיח נעצר לפני המשיחה** (טז, יג): אין בו רוח רעה, אין כינור בחצר, אין חנית מוטלת, אין גוליית ואין סוסים ומרכבות בגבעה. פסוקים מתקופה מאוחרת (כב, ו) ופסוק שנאמר על אליאב (טז, ז) מוצגים עם המקור בלבד.
- **סיפור הדוב** בנוי צעד אחר צעד לפי שמואל א׳ יז, לד–לו: הדוב נושא שה מן העדר, דוד יוצא אחריו, מכה אותו, מציל מפיו, הדוב קם עליו, דוד מחזיק בזקנו, מכה וממית.
- **הרמת השה על הכתפיים** היא תמונה אמנותית: המדרש על הרועה הנושא גדי על כתפו נאמר על משה (שמות רבה ב, ב), ולכן אינו מוצג ככתובית לסצנה הזאת.
- **תקופת הברזל (כ־1000 לפנה״ס)**: שאול בבית אבן מבוצר על גבעה ולא בארמון; אשל על הרמה; חמורים ולא סוסים; מעיל ועליו כנף עם ציצית ופתיל תכלת; נרות שמן פתוחים; אריגים בצמר ארגמן ותולעת שני; אין שעטנז (צמר ופשתים בבגד אחד).
  כנף מעיל שמואל הקרועה בידי שאול היא אמצעי קולנועי: הכתוב (טו, כז) מספר רק שהמעיל נקרע.
- **דוד** — "וְהוּא אַדְמוֹנִי עִם־יְפֵה עֵינַיִם וְטוֹב רֹאִי" (שְׁמוּאֵל א׳ טז, יב): נער צעיר, שיער ערמוני מתולתל, עור שזוף ונמשים, כותונת צמר גסה ולא צבועה, חגורת חבלים, ילקוט הרועים על הירך, סנדלים, מקל מסוקס וקלע ("וַיִּבְחַר־לוֹ חֲמִשָּׁה חַלֻּקֵי־אֲבָנִים מִן־הַנַּחַל וַיָּשֶׂם אֹתָם בִּכְלִי הָרֹעִים" (שְׁמוּאֵל א׳ יז, מ)) — לפי תמונת הייחוס.
- **הנוף והחיות** — רכס בית לחם, מדרגות חקלאיות עם כתלי אבן יבשה, זיתים וברושים, סלעי גיר מחוררים, קרקע טרה רוסה; מצבת קבורת רחל בדרך אפרתה; כבשי עוואסי עם אליה ועזים שחורות; הדוב הסורי (Ursus arctos syriacus), הדוב שחי בארץ ישראל, בפרווה בהירה בגוון קש.

## טכנולוגיית הגרפיקה

- **בני אדם ריאליסטיים** — גופים מבוססי MakeHuman (CC0), בפרופורציות של דוד, שאול ואנשי החצר; עור אפוי במפות 2K/1K (צבע, נורמל, מסכות) עם פיזור אור תת־עורי, עיניים עם קשתית וקרנית, מצמוץ והבעות פנים, אצבעות, ועיוות רך במפרקים (dual‑quaternion skinning).
- **שיער בקווצות** — אלפי קווצות שיער וזקן שנוצרות בזמן הטעינה ומתנועעות ברוח ועם הראש.
- **תלבושות** — בגדים שמותאמים לגוף בזמן הטעינה: הכותונת הארוגה, החגורה, הילקוט והסנדלים של דוד; המעיל, הכותונת, הנזר והחנית של שאול; מרקמי אריג עם ברק בד (sheen) ושוליים מתנועעים.
- **הדוב והעדר** — דוב שפוסל מפונקציות מרחק (SDF) עם 3 רמות פירוט, מפות PBR אפויות, פרווה בשכבות (shells) ואנימציה פרוצדורלית עם IK; כבשים, אילים, עזים וטלה עם רמות פירוט והתנהגות עדר.
- **העולם** — שטח עם מדרגות וכתלי אבן יבשה, סלעי גיר, עצי זית וברוש, עשב שמתנועע ברוח, בית לחם של תקופת הברזל, שמיים ועננים בשעת זהב.
- **בית שאול בגבעה** — תפאורה נפרדת (המצודה, האשל, האולם עם הנרות) ושחקני החצר; נבנים מאחורי מסך הטעינה רק כשהפתיח עומד להתנגן, ומשוחררים מהזיכרון מיד אחריו.
- **שרשרת קולנועית** — TAA (החלקה טמפורלית), עומק שדה, bloom, ערפל אווירה וקרני אור, פס קולנוע 2.39:1 בפתיח, מראה פילם וגרייד חם.
- **דרגות איכות** — בדיקת ביצועים קצרה בטעינה בוחרת דרגה: `desktop-high`, `desktop-medium`, `mobile-high`, `mobile-low`. טלפונים מקבלים תמיד את תוכן ה־low: מרקמים של 1K, פחות קווצות שיער, מעט קריאות ציור, ובלי הורדה של נכסי המחשב; התמונה מצוירת בצפיפות פיקסלים של פי 2 (`mobile-high`) או פי 1.5 (`mobile-low`), ובקצב של עד 60 פריימים בשנייה. אם קצב הפריימים נשאר נמוך לאורך זמן (למשל כשהמכשיר מתחמם), מנגנון ויסות מוריד עומס — קרני אור, bloom ואחר כך רזולוציית הצללים — בלי לשנות את גודל התמונה.
- **סאונד** — כל המוזיקה והאפקטים מסונתזים בזמן אמת (כינור, חליל, תופים, שופר, מקהלה, רוח, ציקדות, עדר); פסקול הפתיח נעול לתמונה.

## מגבלות ידועות

זה עדיין משחק דפדפן שרץ גם בטלפון, ולכן אינו מגיע לרמה של Red Dead Redemption 2. הפנים נראות ריאליסטיות במרחק משחק ובצילומי ביניים, אבל בתקריב קיצוני עדיין מורגש שהן ממוחשבות; הבד והשיער אינם סימולציה פיזיקלית מלאה; והאנימציות הן פרוצדורליות ולא לכידת תנועה.
