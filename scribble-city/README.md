# עיר השרבוטים (Scribble City)

משחק עולם פתוח בדפדפן, שכולו נראה כמו שרבוטים בעט כדורי בשולי מחברת: עיר בסגנון ניו יורק, גורדי שחקים, עבריינים ומפלצות דיו.
הקטע המרכזי: **מצלמים שלטים עם שרטוטים של כלי נשק וכלי רכב, מתחבאים, ומציירים אותם בעצמכם** — בזמן שהעיר ממשיכה לחיות סביבכם.
ככה שהציור מדויק יותר, הפריט חזק יותר. ציור גרוע ייתן פריט שעובד חצי־חצי (נתקע, מפזר, נוסע עקום).

זה החלק הראשון — רובע אחד (5×5 בלוקים) עם כל מערכות הליבה.

## הרצה

אין שלב build. צריך רק שרת סטטי (מודולי ES לא נטענים מ־`file://`):

```bash
cd scribble-city
npx http-server -p 8080 -c-1 .
# או: python3 -m http.server 8080
```

ואז לפתוח http://localhost:8080

## שליטה

| מחשב | טלפון |
|---|---|
| WASD — הליכה, Shift — ריצה, רווח — קפיצה | ג׳ויסטיק משמאל |
| עכבר — הסתכלות, קליק — ירי/מחיקה | גרירה בצד ימין — הסתכלות, כוונת — ירי |
| F — צילום שלט, Q — פתיחת דף הציור | מצלמה / עיפרון |
| E — כניסה ויציאה מרכב, 1-4 — החלפת נשק, M — מפה | כפתורים על המסך |
| ברכב: WASD נהיגה, קליק — תותח/קרן, רווח/C — גובה בחללית | |
| Esc — הפסקה | |

## מהלך המשחק

1. בתחילת המשחק יש מולכם שלט עם שרטוט של **אקדח צבע** — מצלמים אותו (F).
2. מתחבאים (פח אשפה, תא טלפון, שיחים, ארגזים, פיגומים, כניסה לרכבת — מסומנים בעין סגורה) ולוחצים Q.
3. מציירים לפי התמונה. המורה בודקת בעט אדום: ציון, עיגול סביב מה שחסר, ותגובה.
4. השרטוטים הבאים: רובה עפרונות, מכונית שרבוט, בזוקת מחקים, טנק מטורף וחללית חייזרים — כל אחד קשה יותר לציור ונמצא עמוק יותר ברובע.
5. ירייה מוחקת את החלק שנפגע: עבריין יכול להמשיך ללכת בלי ראש או בלי יד, עד שנמחק כולו.

## מבנה הקוד

- `js/render` — מנוע הקווים (קווי עט ברוחב קבוע על המסך, רעד "line boil"), שיידר ההצללה בקווקוו, אטלס הספרייטים והשלטים שמצוירים בקנבס.
- `js/world` — יצירת העיר (רשת שדרות ורחובות, סוגי בלוקים), בניינים, אביזרים, התנגשויות וניווט.
- `js/game` — השחקן, האויבים, כלי הנשק, כלי הרכב, ומזהה הציורים (`recognizer.js`: התאמת chamfer עם כיווניות קווים).
- `js/ui` — HUD, דף הציור, האלבום.
- `tools/` — כלי פיתוח: צילומי מסך headless (`shot.mjs`), תסריטי משחק אוטומטיים (`play.mjs`), ובדיקת כיול המזהה (`npm run test:recognizer`).

Three.js (r169) כלול בתיקייה `js/vendor` ברישיון MIT.
