## המטרה (מהמשתמש)
העיר צריכה להגיע לרמה של GTA IV. מה שהמשתמש ביקש:
- **רחוב:** רחוב עשיר ושוקק, ואנשים שנראים חכמים.
- **מקומות:** חנויות, מסעדות, קניונים ובתים מפורטים כמו במציאות.
- **מראה:** בלי "קוביות לגו".
- **צוות:** צוות סוכנים שעובד במקביל על כל התחומים, "עבודה אינטנסיבית, מקיפה ומהירה".

### מה כל תחום שגמר עשה (בקצרה; הפירוט ב-`reports/`)
- **חזיתות:**
  - חלונות שקועים 15–20 ס"מ בקיר, עם אדן, משקוף, אבן ראש, וילון, תריס או מזגן.
  - מרפסונים עם עציצים או כביסה, כרכובים, מרזבים ומונים.
  - מדרגות חירום על 62% מהבניינים הישנים בני 3 קומות ומעלה, ודלת לדירות.
  - לחנויות: ארגז תריס, שלט על זרוע ומדבקות על הזכוכית.
  - שלושה סגנונות לפי רובע: havana, walkup, deco.
  - נקודות לבלוק: +14.9% בממוצע, ובבלוק הגרוע ביותר +33.5%. קריאות ציור: בערך +1%. בניית בלוק מהירה ב-9%.
- **הולכי רגל:**
  - קבוצות של 2–4 שמדברות בתורות עם תנועות ידיים, מכרים שנפגשים, ושיחות טלפון תוך כדי הליכה.
  - נגן רחוב עם קהל ומטבעות.
  - ארוחת צהריים על ספסלים, ותיירים שמצלמים.
  - ממתינים יחד ברמזור וחוצים יחד.
  - תגובות לשחקן: מבט, צעד הצידה, תלונה.
  - עלות: בלי עלייה מדידה בעבודת המעבד. מספר האנשים לא עלה.
- **תנועה:**
  - בערך 380 מכוניות חונות לאורך המדרכות, ומכוניות בחניונים ובכניסות שעד עכשיו לא צוירו (רק התנגשו בהן).
  - אוטובוסים שעוצרים בתחנות של היבשה.
  - מוניות שעוצרות לנוסעים.
  - טנדרי משלוחים בחנייה כפולה, עם שליח שנושא ארגזים.
  - ניידת שעוצרת רכב.
  - משאית זבל בבוקר.
  - צפירות בפקק.
  - עלות: בערך +0.4ms לעדכון ו-+0.4ms לציור בכל פריים.
- **רחובות:**
  - על הכביש: קווי עצירה, חצי נתיבים, תעלות ניקוז ומכסי ביוב, טלאים וסדקים, וסימוני אופניים.
  - בפינות: רמפות עם משטח צהוב, רמזורי הולכי רגל שעובדים, ושלטי שם רחוב ירוקים עם השמות מהתוכנית.
  - לאורך המדרכה: שפת מדרכה אדומה וצהובה, ושלטים על עמודי הפנסים.
  - בשכונות מגורים: עמודי חשמל מעץ עם חוטים ורצועות דשא. בכל מקום: לכלוך על המדרכה.
  - עלות: נקודות באריחי הרחוב +45% (בטלפון +28%), קריאות ציור +5%.

## איך ממשיכים: צעד אחר צעד

### 1. להחזיר את הענפים מהקובץ
```bash
cd /home/user/Test-1-
git fetch scribble-city/wip/gta4-round2/gta4-round2.bundle 'refs/heads/gta4/*:refs/heads/gta4/*'
git branch --list 'gta4/*' -v     # 6 ענפים. אם הם כבר קיימים מקומית (אותו מכל), אין צורך בזה
```

### 2. להכין את תיקיית העבודה המשותפת לדפדפן
```bash
G=<scratchpad>/gta4          # תיקיית ה-scratchpad של השיחה החדשה
mkdir -p "$G/send" "$G/shots"
cp scribble-city/wip/gta4-round2/tools/* "$G/"
# ב-$G/run_browser.sh לעדכן את LOCK=... לנתיב $G/browser.lock
chmod +x "$G/run_browser.sh"; touch "$G/browser.lock"
```

### 3. לסוקרים של 4 התחומים הבנויים: worktree לכל ענף
הסוקר עובד בתוך ה-worktree של הענף, ומוצא אותו לפי `git worktree list`.
```bash
for k in facades pedestrians traffic streets; do git worktree add .claude/worktrees/gta4-$k gta4/$k; done
```

### 4. להריץ את הצוות
- להעתיק את `workflow_resume.js` לקובץ עבודה, או להעביר אותו כ-script.
- להריץ אותו עם `args: {G: "<הנתיב מצעד 2>", BASE: "30f175c"}`.
- תנאים: Ultracode דלוק. המכונה עם 4 ליבות, כך שרק 2 סוכנים עובדים בו בזמן.

מה הסקריפט עושה:
- **facades, pedestrians, traffic, streets:** סוקר בלבד. הוא קורא את הדוח מ-`reports/` ומתקן ב-worktree מצעד 3.
- **trees, venues:** בונה שעושה `git checkout gta4/<key>` בתוך ה-worktree שלו וממשיך מתמונת המצב. אחריו סוקר.
- **shops, rooftops, homes:** בונה חדש (`git checkout -b gta4/<key>`), ואחריו סוקר.

### 5. מיזוג לענף הראשי
- ממזגים לתוך `claude/serene-hypatia-mj9w2j`, בלי rebase.
- סדר מומלץ: facades, streets, traffic, pedestrians, trees, venues, shops, rooftops, homes.
- כל ענף שייך לקבצים אחרים, כך שלא צפויות התנגשויות. **נקודות לבדיקה:**

  - ייבוא של `shops3.js` ו-`venues2.js` ליד `shops2.js`.
- אחרי כל מיזוג: `node --check` על הקבצים שהשתנו.

### 6. בדיקה משותפת
- דרך `run_browser.sh`: מסלול על כל הדברים יחד, 0 `[pageerror]`.
