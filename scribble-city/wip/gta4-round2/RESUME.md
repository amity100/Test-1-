## איך ממשיכים: צעד אחר צעד

### 1. להחזיר את הענפים
```bash
cd /home/user/Test-1-
git branch --list 'gta4/*' -v     # אם יש כבר 7 ענפים עם אותם ראשים, דלגו על השורה הבאה
git fetch scribble-city/wip/gta4-round2/gta4-round2.bundle 'refs/heads/gta4/*:refs/heads/gta4/*'
```

### 2. תיקיית עבודה משותפת
```bash
G=<scratchpad>/gta4
mkdir -p "$G/send" "$G/shots" "$G/notes" "$G/smoke"
cp scribble-city/wip/gta4-round2/tools/* "$G/"
cp scribble-city/wip/gta4-round2/notes/*.txt "$G/notes/"
cp "$G/lab_smoke_baseline.log" "$G/smoke/main.log"
# ב-$G/run_browser.sh לעדכן את LOCK=... לנתיב $G/browser.lock
chmod +x "$G/run_browser.sh"; touch "$G/browser.lock"
git worktree add --detach "$G/base_main" 6277529
```

### 3. worktree לכל ענף שממשיכים בו
`git worktree list` מראה אם הם עדיין קיימים. אם לא:
```bash
for k in venues trees shops; do git worktree add .claude/worktrees/gta4-$k gta4/$k; done
```

### 4. להריץ את הצוות
- להריץ את `workflow_resume2.js` (Workflow עם scriptPath, או להעביר כ-script) עם:
  `args: {G: "<$G>", BASE: "6277529", FACADES: "c80105e", WT: {venues: "<worktree>", trees: "<worktree>", shops: "<worktree>"}}`
- מה הוא עושה:
  - **venues:** סוקר בלבד.
  - **trees, shops:** בונה שממשיך בתוך ה-worktree הקיים, מההערות ומהתמונה האחרונה. אחריו סוקר.
  - **rooftops** (מתחיל מ-`c80105e`, החזיתות המוכנות) ו-**homes** (מ-`6277529`): בונה חדש ואחריו סוקר.
  - facades, pedestrians, traffic, streets כבר מוכנים, והסקריפט לא מריץ אותם.
- המכונה עם 4 ליבות: רק 2 סוכנים עובדים בו בזמן. סוכנים כותבים הערות שוטפות ושומרים לעיתים קרובות, כך שעצירה לא מוחקת עבודה.
- אם הרצה נעצרת: לשמור (commit) שינויים פתוחים ב-worktree-ים כ-snapshot, ולהריץ שוב. הסוכנים ממשיכים מההערות.
