# מעבדת הגוף (bodylab)

מציירת רק את החלק העליון של הגוף: הז'קט, הצוואר, הראש והשיער. כל חלק מונח במיקום שבו המשחק הניח אותו בפריים אמיתי (`cap.json`), ומצויר משש זוויות בתמונה אחת. תמונה כזאת לוקחת כמה שניות, במקום עשר דקות של בדיקה במשחק המלא. נבנתה בשביל הצווארון (מפת הדרכים 17.4).

## שימוש
- **הגיבור:** `node tools/bodylab/lab.mjs out.png 'subj=hero'`.
- **אדם מהעיר:** `subj=<owner>`, המספר שלו ב־`cap.json`.
- **הפס סביב הצוואר בלי הצווארון הישן:** להוסיף `&band=1`. אפשר גם `&ya=…&yb=…&gap=…`.
- **מדידת הצוואר במידות של הז'קט, לפי גובה:** להוסיף `&measure=1`, או להריץ `node tools/bodylab/measure.mjs` לכל האנשים.

## לשמור פריים חדש
`capture.json` היא בדיקה ל־`wip/shops-remaining/tests/play4.mjs`. היא מתעדת כל חלק שנשלח לציור בפריים אחד, ומדפיסה אותו ביומן בשורות `[cap]`. את השורות האלה מחברים ל־`cap.json`.
