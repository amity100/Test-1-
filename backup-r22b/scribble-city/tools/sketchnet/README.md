# הרשת שמזהה ציורים (v5)

כך נבנית הרשת של `v5/js/game/sketchnet.js`, והמשקלים שלה ב־`v5/js/game/sketchnet_w.js`. ההסבר המלא נמצא ב־`ROADMAP.md`, סעיפים 11.7 ו־11.8.

הציורים מגיעים מ־Quick, Draw! של Google, ברישיון CC BY 4.0. הקבצים של הנתונים לא נשמרים במאגר, וכל שלב מוריד או מייצר אותם מחדש.

```sh
cd scribble-city/tools/sketchnet
python3 -m venv venv && ./venv/bin/pip install numpy jax optax   # נבדק עם jax 0.11, optax 0.2.8
./fetch.sh                               # ההתחלה של כל סוג (כ־16MB לסוג) אל raw/
./venv/bin/python build.py               # data_train.npz, data_val.npz, classes.json (51 סוגים; כ־30 דקות, 4 ליבות)
./venv/bin/python train.py 6             # weights.npz (כ־16 דקות לסבב)
./venv/bin/python export.py ../../v5/js/game/sketchnet_w.js
./venv/bin/python parity.py && node parity.mjs   # הרשת בדפדפן נותנת את אותן תשובות
```

- `classes.txt`: הסוגים מ־11.7 (כלי רכב, נשק, ושמונה דברים אחרים כמו בית ועץ). `classes2.txt`: מה שנוסף ב־11.8 (סירות, כדור פורח, סקייטבורד, מטרייה, סולם, מפתח, גשר, מצנח).
- `render.py`: איך ציור נהיה תמונה של 32×32, בדיוק כמו `picture` במשחק. כאן גם `qd`, ההכנה שעברו ציורי המאגר (והמשחק עושה אותה ב־`ready`), הגרסאות השונות של כל ציור (`augment`), והציורים שנוצרים בקוד בשביל מה שאין במאגר: אקדח, תת־מקלע, רובה ציד, מיניגאן, משגר רקטות, פצצה, טנק, מטוס מהצד, ומ־11.8 גם מגן וקפיץ.
- `train.py <סבבים> [משקלים להמשיך מהם] [שם] [קצב שיא]`: הרשת עצמה (JAX, על המעבד), והדיוק של כל סוג בסוף. משקלים עם פחות סוגים ממשיכים כמו שהם, והשכבה האחרונה גדלה לסוגים החדשים. קצב שיא נמוך (למשל `6e-4`) ממשיך בעדינות ממשקלים שכבר אומנו.
- `export.py <יעד> [משקלים]`: המשקלים כמספרים של בית אחד, עם קנה מידה לכל ערוץ.
- המשקלים שבמשחק נבנו בשלבים: 37 הסוגים של 11.7, אחר כך שני סבבים עם 51 הסוגים (`train.py 2 w3_ep2.npz w4`), ועוד שני סבבים עדינים (`train.py 2 w4_ep1.npz w5 6e-4`).
